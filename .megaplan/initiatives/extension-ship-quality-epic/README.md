# Extension Ship-Quality Epic

This initiative executes the checklist in
`docs/extensions/extension-ship-quality-checklist.md` as five dependent
sprints. The branch starts from `oracle-run-v2`, carries the audited Creative
Lab and Transcript/Runaway work, and pins Astrid `oracle-unified-execution`.

The chain stops on every failure. Completion requires the final release script
and evidence manifest, not narrative status.
