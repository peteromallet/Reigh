No remote-exec hole in V1 (static bundle + `repository: null`). Trust boundary is still “author goodwill.” dataKind newly **hands user payloads to in-tree React** and **routes them by colliding `schemaRef`**.

### HIGH

**1. `schemaRef` first-wins steals the data plane**  
`assembleDataLanes` binds items by `schemaRef`, first snapshot record wins (`assembleDataLanes.ts:79-82`). Snapshot order is `ownerExtensionId` then `kindId` (`DataKindRegistry.ts:173-180`). `kindId` is last-writer-wins (`DataKindRegistry.ts:271-286`). A later/lexicographically-earlier extension that declares `schemaRef: "reigh.transcript_segment/v1"` paints (and receives) every transcript payload; `com.aaa` beats `com.reigh.transcript-lane`. Gate is only same-extension `kindId` (`dataKindRegistrationService.ts:134-145`).  
**Fix:** unique `schemaRef` (or explicit owner); reject cross-extension collide; stop last-writer kind steal.

**2. Lane/inspector are host fibers with full payloads**  
`DataLaneRow` mounts `LaneRenderer` with `payload` (`DataLaneRow.tsx:73-101`); inspector does the same (`PropertiesPanel.tsx:119-130`). Same-thread, same-origin (`docs/extensions/trust-and-security.md:10-23`). Props omit `DataProvider`/`applyEdit`, but a function component can `useAuth()`, `useTimelineEditorOps()`, `fetch()`, `createPortal(document.body)`. Error boundary is a **crash fence**, not a sandbox (`ContributionErrorBoundary.tsx:74-86`; trust doc §4.2).  
**Fix:** before third-party: iframe/ShadowRealm + capability proxy; until then treat dataKind like signed host chrome (`requiresTrustedCode` is docs-only — `familyDefinitions.ts:319`, never a runtime gate).

**3. Kind inspector drops `extensionId`**  
Lane rows pass owner (`DataLaneList.tsx:70`). `DataItemInspectorSection` does not (`PropertiesPanel.tsx:114-118`) → legacy children-reset, no recovery key (`ContributionErrorBoundary.tsx:354-357`). A throwing inspector can crash-loop the panel on playback ticks. Trust §7 table omits data lanes.  
**Fix:** pass `ownerExtensionId`; add lanes/inspectors to the recovery audit table.

### MEDIUM

**4. Opaque inspector stringifies then truncates**  
`PAYLOAD_JSON_MAX_CHARS = 400` applies *after* `JSON.stringify` (`OpaqueDataItemInspector.tsx:47-57`). Huge `text` still freezes the main thread; `toJSON`/getters run (V1 `{text}` from `adaptTranscript.ts:43` is safe; `extraItemsBySchemaRef` is not). Output is a React text node (no HTML XSS; `__proto__` keys do not pollute).  
**Fix:** bounded replacer (depth + string cap) *inside* stringify; never `JSON.parse` the result.

**5. Permissions are labels**  
`ExtensionPermissionDeclaration` is “descriptive until sandboxing exists” (`manifest.ts:213-225`; trust §2). `network: false` does not block `fetch()`. dataKind adds no “read transcripts” even as metadata.  
**Fix:** keep the warning; do not imply gating; add a real transcript-read capability before third-party.

### LOW

**6. `devLocalExtensions` is not an npm injection surface.** Static in-repo imports (`localExtensions.ts:27-33`), production-dropped (`VideoEditorPage.tsx:373-376`), loader `repository`/`bundleStore` null (`:405-407`). A dependency cannot append without editing this file.

**7. Fixture decorator.** DEV + `URLSearchParams.has('transcriptLaneFixture')` (`VideoEditorPage.tsx:463-469`; presence, not `=1`). `Object.create(provider)` + shadow `loadAssetProfile` (`fixtureProvider.ts:31-36`) is in-memory only (does not persist). Prototype `this` on writes can shadow instance fields — DEV footgun, not prod data-loss.

### Third-party bar (would fail review today)

Isolation (not in-tree React), capability enforcement of `permissions`, integrity/signing, user prompts (`trust-and-security.md:166-175`); plus **owned `schemaRef`**, **minimize payloads** (ids/extents only until the owner renders), **DOM confinement** (no host portals), **context firewall** (no host hooks).

**Insight:** dataKind did not add a sandbox — it added a **payload hose** into the existing unsandboxed tree. Error boundaries contain throws; they do not contain `useAuth` or a colliding `schemaRef`.
