## 4. OPEN QUESTIONS (max 4, with recommended defaults)
1. **Bundle storage shape** — column vs sidecar table. **Default: `jsonb` column `timelines.data_bundle`.** One active bundle per timeline; history already lives in `timeline_events`; load path needs no join and inherits RLS. Sidecar table only wins if per-version bundle rows are ever queried independently — nothing in scope does.
2. **Supabase save transport for bundle** — send `bundle` in the `config-replaced` POST body now vs withhold until the Python service adopts it. **Default: send now, degrade-safe.** Additive field; today's service ignores it (same tolerance the bridge contract formalizes); SQL is ready; test pins the request body. Withholding would strand the client half behind an out-of-repo dependency.
3. **`schema_version` validation placement** — solely in the bundle module's Zod parse vs duplicated gates in each provider. **Default: bundle module is the single parse authority; providers call it on load (fail-closed → `bundle:null` + diagnostic) and validate before accepting a bundle for save.** One enforcement point, no drift.
4. **Fate of `extraItemsBySchemaRef`** — delete vs keep-as-deprecated. **Default: delete (clean cutover)** contingent on explore E1 finding no production caller; if a real consumer emerges, repurpose explicitly (rename + docstring declaring mapped-view-only) rather than leave a second ingest seam ambiguous. Design text permits either; deletion is the smaller permanent surface.

## 5. NORTH STAR CHECK
- **Persist source items, not views** ✅ bundle stores `FrozenDataItem` in native domain minus `entityRef`/coords/renderer refs; occurrences derived at assembly (Batches 1, 4). Anti-pattern "persisting views/occurrences" structurally blocked: Zod schema rejects chrome fields.
- **Versioned migratable storage** ✅ `schema_version: 1` header, fail-closed unknown versions, `[CONVERGE-WITH-M1]` local module so M1 renames touch one file (Batch 1). Anti-pattern "unfrozen names baked without version header" avoided.
- **No second database/wire format** ✅ bundle rides the existing save path (append-service event log + `timelines` column; bridge payload; InMemory records) — no new store (Batch 3, 5).
- **Never persist renderer functions** ✅ renderer refs exist only on `DataLaneView`; bundle schema excludes them; functions aren't JSON-serializable anyway.
- **Fail-closed loading** ✅ unknown `schema_version` and corrupt bridge bundle produce diagnostics, never silent partial lanes (crit 3, B6).
- **Per-batch tested seams** ✅ B3 ends provider-round-trip-green; B4 ends full editor save/load/repaint; B5 documents the service-hop gap honestly rather than pretending end-to-end.
