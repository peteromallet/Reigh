- **One authority:** every covered read/write terminates at SQLite + media tree through the loopback bridge; synthetic realtime events are *derived from* bridge reads (one source, one projection) — not a second event authority; IndexedDB draft persistence stays client-cache-only.

- **Growth by declaration:** new capabilities (test binding, render) appear via capability registry availability; the two `instanceof` gates become declared capability flags, killing the last silent behavioral fork between providers.
- **Honest latency:** 2 s/10 s/30 s budgets implemented as declared cadence, not adaptive backoff guessing; `DataFreshnessManager` stability logic consumes declared statuses only.
- **Anti-patterns:** no second placement authority (C2 makes shots a document view); no cloud fallback (grep gate + OS-level block prove absence); no silent executor swaps (family pinned at admission); ceremony avoided by cutting PAT/billing/sharing/referrals/signed-URLs outright rather than shimming; no speculative machinery — every new module names its consumer (journey step).
